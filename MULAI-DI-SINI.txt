LANGKAH ENGLISH

1. Ekstrak ZIP ini terlebih dahulu.
2. Masuk ke folder langkah-english.
3. Klik dua kali index.html untuk mencoba aplikasinya.
4. Klik “Mulai belajar” dan ikuti pelajaran Titik nol.

UNTUK GITHUB PAGES
Upload isi folder langkah-english ke akar repositori.
index.html harus berada langsung di akar repositori.
Di GitHub: Settings > Pages > Deploy from a branch > main > /(root) > Save.
Panduan lebih lengkap ada di README.md.

Tidak perlu npm, akun, API key, atau backend untuk memakai website.
Suara Inggris bergantung pada perangkat/browser.
Progres disimpan di browser; buat cadangan melalui menu Progres.

Materi: 8 dasar + 115 topik, 615 soal inti, 161 kosakata,
8 percakapan, pengulangan, latihan mendengar, dan Campur pola.

Catatan buku dan peta unit: docs/SUMBER-DAN-CAKUPAN.md
Hasil uji dan batas pemeriksaan: docs/PENGUJIAN.md
