# Modul IELTS Writing

Dibuka dari index.html di akar aplikasi, melalui pilihan IELTS Writing. Cakupannya Academic Task 1 dan Task 2 berdasarkan IELTS 19 Academic.

Isi: 20 pelajaran, 60 pertanyaan pendek, delapan tugas buku, delapan tugas baru, draf, riwayat revisi, catatan salah, dan simulasi. Tulisan bebas tidak mendapat band otomatis. Band contoh peserta berasal dari buku; contoh baru belum dinilai pemeriksa.

Berkas entry.js menyediakan kerangka halaman. Konteks host menentukan rute dan kunci data. Timer tetap berbasis waktu berakhir yang tersimpan saat berpindah modul. Tidak ada service worker khusus modul.

Sumber dan catatan versi dasar ada dalam docs modul. Status pengujian integrasi terbaru ada pada docs/PENGUJIAN.md di akar aplikasi. Cara memasang, mencadangkan, dan menambah modul ada pada README.md di akar.
